5. PHONE-HOME VERDICT
---------------------
Code exists but is BLOCKED at three layers:

Layer 1 — Unreachable from Xlet:
  - InitXlet only calls Boot.exec() (lines 599, 615)
  - Boot.run() has ZERO direct callers in the JAR
  - Boot.io() is only called from Boot.run() itself

Layer 2 — Malformed if reached:
  - InitXlet:560 sets Boot.EP = this.discRoot (a file:/ or bd:/ URL)
  - Boot.io() casts openConnection() result to HttpURLConnection
  - FileURLConnection is NOT an HttpURLConnection → ClassCastException

Layer 3 — BD-J permission denies:
  - bluray.InitXlet.perm grants: applifecyclecontrol, bd-bindingunitarea,
    bd-vfs, file, servicesel, userpreferences
  - NOT granted: Connector.http, Connector.socket, Connector.ssl
  - Any http:// openConnection() throws SecurityException

Residual risk: cmd-0043.bin DOES attempt Boot.run() via reflection
  (op 10 getMethod + op 29 Thread). Even if it fires, Layers 2 & 3 block it.
